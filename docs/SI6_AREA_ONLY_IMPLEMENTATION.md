# Si6 live area-only implementation

Use [REAL_INSTRUMENT_RUN_COMMANDS.md](REAL_INSTRUMENT_RUN_COMMANDS.md) for ready-made COM4/COM6 configs and commands. This report records the preceding control refactor; packaging required only focused configuration and command checks.

1. **Files changed:** live control in `chemyx_lab/workflows/three_instrument_si6.py`, `si6_automated_nmr.py`, `si6_profile.py`; measurement/identity/endpoint functions in `chemyx_lab/analysis/stage_measurement.py`, `peak_tracking.py`, `stage_completion.py`; reporting in `si6_final_qc.py`, `final_nmr_summary.py`, `si6_stage_reports.py`; production CLI in `scripts/nmr/process_fid.py`, experiment CLI, four current two-stage templates, associated guides, synthetic-analysis adapters and focused tests. The seven real YAML files and diagnostic CLI additions are documented in the runbook.
2. **Previous behavior:** QC-qualified observations, bounded absence, uncertainty, metadata-time minimums, window ranges/slopes and several confirmations could prevent progression or classify analysis as inconclusive.
3. **Current behavior:** identify the continuity-tracked peak, record moving trapezoidal area, evaluate configured area endpoints. Successfully processed spectra with no qualifying identity record area 0 and retain the last detected identity. Stage entry after the initial CLI confirmation is automatic.
4. **Stage 1 endings:** the near-zero endpoint completes the stage and authorizes the protected dose; iteration/duration ceilings, interruption or operational/safety failure stop the experiment without authorizing a dose.
5. **Stage 2 endings:** growth plus the stable-area endpoint completes the experiment; iteration/duration ceilings, interruption or operational/safety failure stop it. Limits never mean chemistry completion. QC warnings are not endings.
6. **Stage 1 maximum:** `completion.max_iterations: 20`, the single explicit count limit. Exhaustion returns `STAGE_1_MAX_ITERATIONS_REACHED` (exit 10).
7. **Stage 1 threshold/count:** `near_zero_fraction: 0.025`, `consecutive_iterations: 3`. Each comparison is `area / max(abs(initial_area), epsilon) <= 0.025`; larger values reset the count. An initially absent peak can satisfy the endpoint after three zero observations under this intentionally simple rule.
8. **Stage 2 growth:** `minimum_growth.enabled: true`, `fraction_of_initial: 0.25`; growth is `(max_seen_area - initial_area) / max(abs(initial_area), epsilon)`. Epsilon is `1e-12`; an initially zero signal uses that denominator. The growth observation starts a fresh stability window.
9. **Stage 2 stability:** `relative_change_threshold: 0.02`; each adjacent comparison is `abs(current - previous) / max(abs(previous), epsilon) <= 0.02`. There is no historical-maximum proximity, slope, duration or uncertainty requirement. A later stable level can qualify after growth has occurred.
10. **Stage 2 count:** `consecutive_iterations: 4` means four observations and three stable adjacent pairs after growth; earlier flat observations cannot count. Maximum is 20 observations; exhaustion returns `STAGE_2_MAX_ITERATIONS_REACHED` (exit 11).
11. **Integration:** `chemyx_lab.analysis.nmr.pick_spectrum_region` produces `RegionPeak.positive_area` with `_trapezoid(np, np.maximum(area_y[order], 0.0), area_x[order])`, using `numpy.trapezoid` or the older `numpy.trapz` fallback. Bounds follow the interpolated center and measured width. `tracked_peak_area_observation` consumes retained lossless production evidence, rather than rounded CSV values.
12. **Identity:** `chemyx_lab.analysis.stage_measurement.select_candidate` is reused through `tracked_peak_area_observation`; `peak_tracking.identification_config` enables only explicit search, continuity, position-shift, prominence, width and separation settings. Previously identified neighbors cannot silently replace a lost target.
13. **No fixed integration band:** configured search windows restrict identity selection; integration follows the detected center and width. Fixed target/statistics replay and display-only flattening are excluded from this live processor path.
14. **QC isolation:** `area_completion_evidence` reads only `peak_area`. SNR/height/area/shoulder rejection, uncertainty, timing availability and reporting QC flags do not decide endpoints. Configured prominence/width/search controls remain explicit peak-identification settings. QC-dependent automatic reference selection is disabled for this live path; the metadata ppm axis is used consistently.
15. **Inconclusive isolation:** QC flags cannot produce `ANALYSIS_INCONCLUSIVE` in the new live profile. Missing/corrupt processor evidence, invalid raw data or a processor crash remains an operational failure, never zero area that could authorize dosing.
16. **Reports:** `<run>/final_qc/` contains `qc_summary.csv`, `qc_summary.json`, `qc_report.md`, `plot_manifest.json`, and peak position/area/SNR/width plots in PNG/SVG/PDF. These retain candidate decisions, bounds, raw hashes/paths, phase evidence, noise/uncertainty, warnings and stage/dose summaries. Reports run after terminal decisions; reporting failures cannot change the outcome. Dataset identities are visible in titles/manifests. Time plots share one CSV and use JCAMP LONG DATE only; unavailable timing omits plots without stopping area control or substituting filename/mtime.
17. **Checks:** `tests/test_si6_area_only.py` adds 31 cases covering ignored QC flags, production moving areas, old noise-QC counterexamples, missing peaks/neighbor identity, distinct limits, no extra dose, processor failure, missing timing, dataset titles and all plot formats. The corrected affected subset completed with **82 passed**; the last focused production/monitoring/identity/report subset completed with **94 passed**. These finished before packaging; no new broad suite was started. Packaging loaded all four real experiment files with both ports, confirmed the single port difference and unchanged nominal chemistry, checked explicit Channel 1/2 routing and finishing-change Python imports/syntax. CLI configuration-only checks passed without opening hardware.
18. **Remaining QC-dependent paths:** historical `tracked_peak_measurement` and statistical completion remain for offline audits/tests, plus standalone legacy analysis/diagnostic tools. Historical two-stage profiles are rejected for live execution. They do not drive the new `si6_real_two_stage.yaml` controller. Instrument errors, STOP verification, capacity/needle state, timeouts and the durable at-most-once dose ledger remain enforced.

Successful path: one initial `y` → Stage 1 → confirmed Channel 2 dose exactly once → automatic Stage 2 → final cleanup. No Stage 2 readiness prompt is issued.
