Module data

1D and 2D data analysis and export.

In the Experiment Designer, data is acquired one DataSet1D at a time. These can be collected together into a Results2D, then processed and displayed and/or exported.

Parameters:

Core.automaticBaselineCorrection(dataSet, method, param1, param2)
Perform an automatic baseline correction. Available methods: 1 = Asymmetic least squares (dParam1= lambda, dParam2= p), 2 = Pan Tompkins (dParam1= fit method, dParam2= safety margin), 3 = lowess (dParam1= span), 4 = Rlowess (dParam1= span), 5 = manual: (dParam1= 1 gives spline, = 2 gives polynomial, = 3 gives pchip) (if polynomial, dParam2= order)

Parameters:

  • dataSet DataSet1D The data to use when creating the baseline correction.
  • method int The method to use.
  • param1 double First parameter for the given method (see above)
