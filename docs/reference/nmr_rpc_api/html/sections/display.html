Class DisplayDataTable

A DataTable results display. Inherits from DisplayElement.
DisplayDataTable.DisplayDataTable(page, mArgs)
Construct class from a map of key/value pairs, each in string format.

Parameters:

  • page DisplayPage The page to add the display to.
  • mArgs map<_string,_string_>

    The parameters to use for this element. See DisplayElement for details. Additional keys are:

    • nextentrybutton: "true" or "false".
    • legend: "upper right", "upper left", "lower left", "lower right", "right", "center left", "center right", "lower center", "upper center", or "center".
    • cursorformat: Format for the cursor text. Must contain two format specifiers, e.g. "x: %.2f,\ny: %.1f".
    • xAxisTickLabelFormat: Format for the x axis ticks. Must contain one format specifier, e.g. "%.1f ms"
    • expandedYUpper: Y axis bounds expansion factor (upper.)
    • expandedYLower: Y axis bounds expansion factor (lower.)

Class DisplayElement

A generic type of display element.
DisplayElement.DisplayElement(mArgs, t)
Construct class from a map of key/value pairs, each in string format. Do not create a DisplayElement directly. Use one of the derived classes instead.

Parameters:

  • mArgs map<_string,_string_> A map (table) of optional string parameters to use when creating the object. Available keys are: "pageName", "name", "datasetName", "datasetIndex", "row", "column", "rowspan", "columnspan", "rowStretch", and "columnStretch".

Class DisplayLabel

A text label. Inherits from DisplayElement.
DisplayLabel.DisplayLabel(page, mArgs)
Construct class from a map of key/value pairs, each in string format.

Parameters:

  • page DisplayPage The page to add the display to.
  • mArgs map<_string,_string_> The parameters to use for this element. See DisplayElement for details. Additional keys are: "text" and "alignment". Alignment options are comma separated and case sensitive. Horizontal options: "AlignLeft", "AlignRight", "AlignHCenter", "AlignJustify". Veritcal options: "AlignTop", "AlignBottom", "AlignVCenter". Two-dimensional option: "AlignCenter". You can only specify one flag for each dimension.
