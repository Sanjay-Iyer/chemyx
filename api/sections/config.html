PhaseCycling

PhaseCyclingMode
Constants: Modes for phase cycling.

Fields:

  • Off 0, No phase cycling.
  • Paps 1, PAPS phase cycling.

Usage:

    PhaseCycling.Off

DecouplingType

DecouplingType
Constants: The type of decoupling to apply.

Fields:

  • Off 0, No decoupling.
  • Waltz16 1, Waltz16 Decoupling.
  • BBWaltz16 2, BB-Waltz16 Decoupling.
  • End , An invalid selection, past the end of the list.

Usage:

    DecouplingType.Off

DecouplingMode

DecouplingMode
Constants: The decoupling mode.

Fields:

  • Off 0, No decoupling.
  • Gated 1, Decoupling is performed before the pulse sequence.
  • InverseGated 2, Decoupling is performed during the signal acquisition.
  • On 3, Both Gated and InverseGated are used.
  • End , An invalid selection, past the end of the list.

Usage:

    DecouplingMode.Off

SuppressionMode

SuppressionMode
Constants: The suppression mode.

Fields:

  • Off 0, Suppression is turned off.
  • On , Suppression is turned on.
  • End , An invalid mode, past the end of the list.

Usage:

    SuppressionMode.Off

SimultaneousLockMode

SimultaneousLockMode
Constants: The type of simultaneous lock to apply.

Fields:

  • Off 0, No simultaneous lock.
  • Single , Single acquisition mode.
  • Continuous , Continuous mode (slow frequency lock)
  • Feedback , Continuous mode (rapid feedback lock)

Usage:

    SimultaneousLockMode.Off
