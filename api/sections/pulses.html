setWaitForDigitalInput(wait)
Wait for the digital input (DIGI1) to start. Normally, acquire() causes an acquisition to start as soon as possible (as soon as configured). This method can be used to wait for an input condition before starting the acquisition (pulse sequence). If lock is enabled, the "acquisition" includes the first lock. If lock is disabled, the "acquisition" is the main pulse sequence. DIGO5 will be set to "high" when the system is ready for the input condition (a falling edge on DIGI_1.)

Parameters:

  • wait bool If true, wait for DIGI_1 before the pulse sequence starts. To disable waiting and return the timeout to the default value, set this to false.

Core.setDigitalOutput(which, on)
Set a digital output to on or off. It will be set this way until it is changed in one of several ways: 1. This method is called again to change it. 2. There is an acquisition error, in which case the hardware is reset and the output is set to its default state. 3. The output is changed in a pulse sequence (not yet supported.)

Parameters:

  • which unsigned_int The output pin identifier (1, 2, 3, 4, or 5)
  • on bool True: Set the output to "on", False: Set the output to "off"

DdsDriveStrength

DdsDriveStrength
Constants: AD9959 configuration related items.

Fields:

  • Undefined -1, The DDS Drive Strength is undefined.
  • EighthScale 0, The DDS Drive Strength is 1/8 (0)
  • HalfScale 1, The DDS Drive Strength is 1/2 (1)
  • QuarterScale 2, The DDS Drive Strength is 1/4 (2)
  • FullScale 3, The DDS Drive Strength is 1 (3)

Usage:

    DdsDriveStrength.Undefined

CPDState

CPDState
Constants: The state to set the Composite Pulse Decoupling to.

Fields:

  • Automatic 0, Non-custom decoupling.
  • Start 1, Turn on decoupling.
  • Stop 2, Turn off decoupling.
  • Blank 3, Temporarily pause decoupling.
  • Unblank 4, Resume decoupling.

Usage:

    CPDState.Automatic
