Saving Results

There are several types of data that can be exported during an experiment. 1D results, 2D results, data tables, log messages, and more. A script may automatically save results, or saving can be initiated via the 'Save' button on the results screen.

Save button

In order for the 'Save' button to work, the script must create a 'save()' function. The save function will have one parameter passed to it, the filename the user enters using the on-screen keyboard. The save function should return a table (array) consisting of a boolean (success) and a string (message). If the save function returns just a boolean, it will still work, but it is recommended to return a message as well.

When using a custom save() function, you should put the function definition near the top of the script, before any acquisitions take place. The reason for this is that the script is interpreted one line at a time, and the save() function will not be created until its lines of code have been run through the interpreter. If a script is cancelled before the save function is defined, it will not be available for the Save button to use it.

Here is an example of a save function that saves a DataSet1D whose Lua object is named 'dataSet'. Note: If the script was cancelled before 'dataSet' was created, it can not be exported and it will have the value 'nil' if tested using 'if'.

function save(fileName)
    local success = false
    local message = "Could not save, the data did not exist!"
    -- dataSet must be global
    if dataSet
    then
        exportDataSet1D(dataSet, fileName)
        message = "Saved to " .. fileName
        success = true;
    end
    return { success, message }
end

acquire()
-- Note: dataSet is global, not local
dataSet = core:core:dataSetSignal()

1D Results Export

After the acquire() statement, data is available for export and/or display.

If you would like to export 1D data, you can do so with the exportDataSet1D function:

exportDataSet1D(core:dataSetSignal(), "my_filename")

2D Results Export

Multiple DataSet1D objects can be collected into a single result object, a Results2D.

-- Create a pulse sequence with 1 pulse.
-- The length of the pulse will be changed in this experiment.
local p = PulseSequence()
p:add(newPulseSingle())
-- Perform acquisitions and put them in an object named "results"
-- (See '2D Results Export' section for a complete example)
results = newResults2D("nutation")
local startWidth = 10e-6
local endWidth = 100e-6
local numSteps = 11
for i = 1, numSteps do
    -- Set the length of the first pulse
    local pulseTime = (startWidth +
                       (i - 1) * (endWidth - startWidth) / (numSteps))
    p:setPulseTime(0, pulseTime)
    acquire()
    -- Append the 1D acquisition to the 2D results
    results:addDataSet(core:dataSetSignal())
done
-- Export a result to a file named "my_nutation"
exportResults2D(results, "my_nutation")

Exporting Log Messages

The log messages are normally displayed on the screen and not saved to disk. These messages are trimmed and old ones are eventually lost.

If you would like to save the log messages, set the log file name in your experiment using setLogFileName(). After setting it, subsequent log messages will be shown on screen and will be saved in the log file. The log file name will have ".log" appended to it.

Log messages can only be saved to one file at a time, but you can change the file at any time by calling setLogFileName() again.

-- After this, log messages will be saved to "my_experiment.log"
setLogFileName("my_experiment")
for i = 1, 10 do
    -- Change some parameters, then acquire()
    ...
    acquire()
    log("FD Peak Magnitude: %f", core:dataSetSignal():fdMagPeak())
end

Exporting Data Tables

A data table is a relatively small collection of data compared to a 1D or 2D spectrum. It is simply a list of X values with one or more lists of Y values. A row is considered one X value and one Y value in each list. If you have a single list of Y values, then a row contains one X value and one Y value.

-- Create a data table
dataTable = newDataTable("Nutation", {xUnits = "uS"})
-- Add a column
dataTable:addEntry({name = "Pulse Time",
                    label = "Pulse Time",
                    fitFunction = "Damped Wave"})
local startWidth = 10e-6
local endWidth = 100e-6
local numSteps = 11
for i = 1, numSteps do
    -- Set the length of the first pulse
    local pulseTime = (startWidth +
                       (i - 1) * (endWidth - startWidth) / (numSteps))
    p:setPulseTime(0, pulseTime)
    acquire()
    local peakIndex, peak = core:dataSetSignal():fdMagPeak();
    local absPhase = math.abs(core:dataSetSignal():fdPhase(peakIndex))
    if (absPhase >= 90 and absPhase <= 180)
    then
        peak = peak * -1
    end
    dataTable:append(pulseTime * 1e6, { peak })
done
exportDataTable(dataTable, "nutation_data")

Multiple Results Export

To export multiple kinds of results at once, you can use a zip file. To do this, first create a directory. Then save your results there. Finally, compress the directory. After the directory is compressed, it will be removed from disk.

-- Create the results directory
prepareExperimentResults("my_experiment")
-- Log messages will now go in the results directory in a file
-- named "my_experiment.log"
setLogFileName("my_experiment/my_experiment")
-- Perform a reference scan and save it to a file in the results
-- directory
acquire()
exportDataSet1D(core:dataSetSignal(), "reference")
-- Perform acquisitions and put them in an object named "results"
-- (See '2D Results Export' section for a complete example)
results = newResults2D("2d_results")
for i = 1, N do
    -- Change some parameters, then acquire()
    ...
    acquire()
    -- Append the 1D acquisition to the 2D results
    results:addDataSet(core:dataSetSignal())
end
-- Export a result to a file named "result" in the "my_experiment" directory
exportResults2D(results, "my_experiment/2d_results")
-- Compress the results in the "my_experiment" results directory.
-- This creates a file, "my_experiment.zip" that contains the
-- files in that directory.
compressExperimentResults("my_experiment")
