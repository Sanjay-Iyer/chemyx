# 04_set_volume.txt  —  SET VOLUME  (the SIGN sets the direction!)
# What it does : sets the target volume to move.
#   POSITIVE volume  = INFUSE  (dispense)
#   NEGATIVE volume  = WITHDRAW (aspirate)
# Expected echo: the pump replies   volume = 0.5   (or  volume = -0.5)
# Channel (4000X): prefix the channel number, e.g.  "2 set volume 0.5".
# REMINDER: press Enter (carriage return, \r) after each command line.
# NOTE: lines starting with # are notes for YOU — do NOT type them.
#       Send ONLY ONE of the two lines below depending on direction.
# ------------------- SEND ONE LINE BELOW -----------------------------
set volume 0.5
# ...or, to withdraw instead, send this one:
set volume -0.5
