# 01_set_units.txt  —  SET UNITS
# What it does : sets the flow-rate units for the pump.
#   Codes:  0 = mL/min   1 = mL/hr   2 = uL/min   3 = uL/hr
# Expected echo: the pump replies   units = mL/min
# Channel (dual-channel 4000X): prefix the channel number to target one
#   drive, e.g.  "2 set units 0"  ; no prefix = default/both.
# REMINDER: press Enter (carriage return, \r) after the command line.
# NOTE: lines starting with # are notes for YOU — do NOT type them.
# ------------------- SEND THE LINE BELOW -----------------------------
set units 0
